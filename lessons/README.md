# 🌱 从零开始学写代码（练习分支）

这个分支和你的真实 App 分开，写坏了也没关系。

## 我们怎么学
1. 我在 `lessons/` 里放当天的课（例如 `lesson-01.md`）
2. **你**在 GitHub 网页上新建文件、自己敲代码（不要复制粘贴，敲一遍才会记住）
3. 保存（Commit）到 `practice` 分支，然后告诉我
4. 我把你的代码跑一遍，**把效果截图发给你**，并告诉你哪里对、哪里可以更好

## 课程表
- [ ] 第 1 课：第一个网页 + 一个会动的按钮（HTML + JavaScript）
- [ ] 第 2 课：做一个「卡路里累加器」（变量、输入框、加法）
- [ ] 第 3 课：用列表保存你吃的东西（数组、循环）
- [ ] 第 4 课：保存数据，关掉网页也不会丢（localStorage）
- [ ] 第 5 课：加入热量目标和进度条（把前面合起来）

做完第 5 课，你就等于亲手写出了「轻卡」的核心功能。
